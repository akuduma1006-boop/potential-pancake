# ☢ NukeCraft

Мод для [Horizon](https://playhorizon.dev/) (Minecraft: Java Edition 26.3, переписанный на Rust).
Нативный Rust-мод на `horizon-mod-api`.

**Ядерный пульт**: выбираешь оружие в меню, наводишь прицел, жмёшь ПКМ, и с неба прилетает удар.

| Управление | Что делает |
|---|---|
| **ПКМ** пультом | удар выбранным оружием в точку прицела (до 400 блоков) |
| **Shift + ПКМ** | меню выбора оружия |
| **ЛКМ** по карточке | выбрать оружие (меню закроется) |

## Оружие

| Код | Название | Радиус | Особенность |
|---|---|---|---|
| NK-01 | Фугасная ракета | 6 | для разминки |
| NK-02 | Тактический заряд | 14 | маленький гриб |
| NK-03 | Ядерная бомба | 30 | вспышка, ударная волна, гриб |
| NK-04 | Царь-бомба | 55 | самое мощное |
| NK-05 | Метеорит | 20 | летит под углом, магма и обсидиан |
| NK-06 | Орбитальный луч | 7 | прожигает мир до самого низа |

## Установка

Нужны [Rust](https://rustup.rs) 1.95+, лаунчер Horizon и инстанс с версией Nightly.

1. Поставить инструмент для модов:
   ```sh
   cargo install --locked --git https://github.com/horizon-rust/horizon cargo-horizon-mod
   ```
2. В папке мода скачать SDK закреплённой сборки (папка `.horizon/sdk/`):
   ```sh
   cargo horizon-mod check
   ```
   Если твой инстанс на более новой Nightly: `cargo horizon-mod update`.
3. Собрать мод под инстанс:
   ```sh
   horizon-launcher native-build . --instance "Мой инстанс" --trust-native-code
   ```
4. Запустить игру, взять пульт (`/give @s nukecraft:nuke_remote`) и пользоваться.

## Устройство

```
src/
├── lib.rs      хуки мода, регистрация пульта и ключей
├── weapons.rs  каталог оружия: новое оружие = одна запись
├── menu.rs     экран меню (клиент): панель пульта и карточки оружия
├── net.rs      сеть: Fire (клиент → сервер), Boom (сервер → клиент, тряска камеры)
└── strike.rs   сервер: прицел, полёт, волна взрыва, обугливание, ядерный гриб
assets/, data/  предмет пульта: текстура, модель, названия
```

Воронка вырезается **слоями**: каждый тик ударная волна растёт на `wave_speed` блоков, и сервер
удаляет только новый слой шара массовым `edit_blocks` (колоннами). Тест
`wave_steps_add_up_to_the_whole_ball_once` проверяет, что слои вместе дают весь шар,
каждый блок ровно один раз.
